Vulnerability Report Template

Title

[Issue type] affecting [feature or endpoint]

Summary

Describe the vulnerability and the security control that fails.

Target

- Authorized asset:
- Endpoint or feature:
- Required account role:

Preconditions

List the permissions and test conditions required.

Reproduction Steps

1. Authenticate using an authorized test account.
2. Open the affected feature.
3. Perform the minimal safe test.
4. Record the observed result.

Expected Behavior

Explain what the application should do.

Actual Behavior

Explain what happened instead.

Impact

Describe realistic confidentiality, integrity, or availability consequences. Do not exaggerate impact.

Evidence

Attach sanitized screenshots or relevant request/response excerpts. Remove credentials, session tokens, and personal information.

Remediation

Recommend a specific server-side security control or code change.

Severity

Propose a severity level and justify it using the program's published criteria.

Limitations

State any untested assumptions and the boundaries of the validation.
