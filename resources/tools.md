Bug Bounty Tools

A categorized list of tools for authorized security research.

Web Application Testing

- Burp Suite Community Edition — HTTP interception and request analysis.
- OWASP ZAP — Web application security testing.
- Browser Developer Tools — Client-side debugging and request inspection.
- curl — Controlled HTTP requests.

Reconnaissance

- Amass — Attack-surface mapping.
- Subfinder — Passive subdomain discovery.
- httpx — HTTP service probing.
- Katana — Web crawling.
- Nmap — Authorized network and service discovery.

Vulnerability Research

- ffuf — Content discovery.
- Nuclei — Template-based security checks.
- Semgrep — Static code analysis.
- Gitleaks — Secret detection.
- OWASP Dependency-Check — Dependency vulnerability analysis.

Safe Practice Environments

- OWASP Juice Shop
- PortSwigger Web Security Academy
- WebGoat
- DVWA (Damn Vulnerable Web Application)

Important

Use these tools only against systems you own or have explicit permission to test. Configure scanning rates carefully and follow the relevant program's rules.
