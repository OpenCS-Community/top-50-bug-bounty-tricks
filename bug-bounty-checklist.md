# Bug Bounty Checklist

## Before Testing
- [ ] Read program scope and rules.
- [ ] Confirm the asset is authorized.
- [ ] Review rate limits and prohibited techniques.
- [ ] Prepare test accounts and synthetic data.

## During Testing
- [ ] Map the application's features.
- [ ] Record normal behavior.
- [ ] Review authentication and authorization.
- [ ] Inspect input handling and API responses.
- [ ] Validate findings with minimal, safe tests.
- [ ] Stop if testing risks real users or service availability.

## Before Reporting
- [ ] Confirm the issue is reproducible.
- [ ] Document expected and actual behavior.
- [ ] Explain realistic security impact.
- [ ] Sanitize screenshots and request/response evidence.
- [ ] Include remediation advice.
- [ ] Submit through the approved private reporting channel.
