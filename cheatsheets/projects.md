Each project includes:

- **Difficulty** — 🟢 Beginner • 🟡 Intermediate • 🔴 Advanced
- **Skills learned**
- **Solution / reference repo** — where to see how others built it

**Rule:** Build first, then look at the solution. Copying defeats the purpose.

## Suggested Learning Path

### 🟢 Beginner (Months 1–3)
1. Build a calculator, to-do list, weather app
2. Learn Git + GitHub basics
3. Solve 50 LeetCode easy problems
4. Complete TryHackMe beginner path

### 🟡 Intermediate (Months 4–9)
1. Full-stack blog or e-commerce
2. Complete 100 LeetCode problems
3. PortSwigger Academy: all web vulns
4. Build 3 bug bounty recon tools
5. Deploy 2 projects to the cloud

### 🔴 Advanced (Months 10–18)
1. Build a Redis/SQLite clone
2. Train a neural network from scratch
3. Complete HackTheBox machines
4. Build a SaaS product
5. Contribute to 5 open-source repos
